# shop_gui
1. Создать виртуальное окружение
py -m venv venv
2. Активировать его
venv\Scripts\activate
3. Установить зависимости
pip install -r requirements.txt
4. Запустить
py main_window.py
5. Сборка .exe (PyInstaller)

venv\Scripts\activate
pip install pyinstaller
pyinstaller main_window.spec

Готовый файл: `dist/Магазин.exe`

P.S. 
- Отключить окружение 
deactivate
- Удалить окружение
rmdir /s venv
- авто requirements
pip freeze > requirements.txt
